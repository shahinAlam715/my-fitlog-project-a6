# 🏋️ My-FitLog-Project

A modern **fitness workout planning web application** built with **Next.js, TypeScript, Tailwind CSS, and React Context API**.

FitLog allows users to browse workouts, add exercises to their daily plan, save workouts for later, sort exercises, and track workout duration, calories, and ratings through a responsive dark-themed interface.

---

## 🚀 Technologies Used

* **TypeScript**
* **React**
* **Next.js**
* **Tailwind CSS**
* **DaisyUI**
* **React Context API**

---

## ✨ Key Features

### 1. 🏋️ Workout Library

Browse a collection of workouts with detailed information including:

* Muscle Groups
* Equipment
* Difficulty
* Duration
* Calories Burned
* Rating
* Workout Instructions

### 2. 📋 Daily Workout Plan

Add exercises to **Today's Workout Plan** and manage selected workouts from a dedicated plan section.

### 3. 💾 Save for Later

Save favorite workouts for later and access them anytime from the **Saved Workouts** section.

### 4. 📊 Workout Tracking & Sorting

Track your:

* Total Exercises
* Workout Duration
* Calories Burned

Workouts can also be sorted by:

* Duration
* Calories
* Rating

### 5. 🌙 Responsive Dark UI

A modern fitness-focused **dark-themed interface** designed with Tailwind CSS and optimized for:

* 📱 Mobile
* 💻 Desktop
* 📲 Tablet

---

## 🎯 Project Goal

The main goal of FitLog is to provide a simple and organized way for users to **discover workouts, create daily workout plans, save exercises, and monitor their workout activity**.
